# Proposal · P1 导航首页（iTab 风格新标签页）

> 版本：v1.0（2026-11-10）
> 状态：待 review（人工确认后才 apply）

## 为什么做（Why）

VeythCog 目前的落地页是工作台（对话 / 知识库 / 工具集），没有一个「进门即见」的门户页。
作为个人浏览器起始页，需要一块独立的全屏首页：

- 替代浏览器默认新标签页，一打开就看到时钟、常用网站搜索、自定义书签；
- 与现有工作台解耦：首页是「壳」，工作台入口（对话 / 知识库 / 工具集）作为右上角头像下拉或顶部一个入口存在；
- 复用现有基础设施：JWT 登录态、S3（`public-icons` 桶存书签图标、`wallpapers` 桶存壁纸）、PostgreSQL、React+AntD+Zustand。

参考样式：用户提供的 iTab 截图（全屏壁纸 + 居中大时钟 + 搜索框 + 两行图标网格 + 右侧竖排分类栏）。

## 做什么（What）

新增一个前端路由 `/home`（或直接作为根路径 `/` 的首页壳），后端新增 `vc-nav` 模块提供分类与书签 CRUD。

**核心界面元素（自上而下、自中而右）**：

1. **全屏壁纸**：S3 `wallpapers` 桶随机取一张，每次进入首页随机；用户可在设置里锁定某张。
2. **顶部居中**：大时钟（`HH:mm`）+ 公历日期 + 农历日期。
3. **搜索框**：居中圆角搜索条，左侧可切换搜索引擎（百度 / Google / Bing），回车新窗口跳转。
4. **书签网格**：两行图标（每行最多 10 个），每个图标 = logo + 名称，最后一个固定为「+ 添加图标」。
5. **右侧竖排分类栏**：平时隐藏不打扰，**鼠标靠近右边缘（20px 热区）时从右侧滑入**；纵向排列当前用户的所有分类（主页 / 后端 / 前端 / 学习 / 工具 / 游戏 / AI / + 新建），当前分类高亮；鼠标离开后延迟 1.5s 滑出。
6. **底部**：一句文案（节气 / 励志 / 诗词，P0 先写死几条轮播）。
7. **右上角**：用户头像 + 下拉（进入工作台 / 切换壁纸 / 编辑分类 / 退出登录）。

**核心交互（用户重点强调）**：

- **鼠标在整个图标页面区域（书签网格主区域）上下滚动 → 切换分类**（向上滚切上一个、向下滚切下一个），书签网格淡入淡出；不需要精准瞄准右侧竖栏；
- **每个分类独立维护自己的书签列表**，切分类不丢当前分类的排序；
- 自定义书签：弹窗填写名称 / URL / 图标（前端直接拼 `https://{domain}/favicon.ico`，加载失败用「网站名前 3 字 + 占位色块」兜底）；
- 自定义分类：重命名、排序、删除（**分类下有书签时不支持删除**，必须先把书签全部移走或删除）。

## 范围（Scope）

### In-scope（P0 本轮交付）

1. **后端 `vc-nav` 模块**（新建，遵循 `common ← (chat, knowledge, nav) ← app` 依赖方向）：
   - `nav_category` 分类表 + `nav_bookmark` 书签表 + `nav_setting` 用户首页配置表；
   - 分类 CRUD、分类排序（拖拽前后端同步）；
   - 书签 CRUD、书签排序（拖拽前后端同步）；
   - 壁纸列表与随机取一张（走 S3 `wallpapers` 桶预签名，复用 `S3PresignService`）；
   - **不做 favicon 代理接口**——前端直接拼各站 `https://{domain}/favicon.ico`，失败用「网站名前 3 字」兜底。
2. **前端新首页 `/home`**：
   - 全屏壁纸背景 + 居中布局；
   - 时钟组件（实时走秒）；
   - 搜索框（百度 / Google / Bing 三引擎切换，回车跳转）；
   - 书签网格组件（两行，响应式：宽屏 10 列、中屏 8 列、窄屏 6 列）；
   - 右侧竖排分类栏 + **滚轮切换分类**（wheel 事件 + debounce 300ms，淡入淡出过渡）；
   - 添加 / 编辑书签 Modal；
   - 添加 / 编辑 / 删除分类（右上角「编辑分类」入口进入管理态）。
3. **登录态复用**：未登录访问 `/home` 自动跳 `/login`；登录后默认进入 `/home`。

### Out-of-scope（P0 不做，明确延后）

- ❌ 壁纸上传：P0 先从 S3 `wallpapers` 桶预放 20 张，用户只能在已有列表里随机 / 锁定，不能上传；
- ❌ 农历 / 节气：P0 先显示公历日期，农历用前端 `lunar-javascript` 库兜底（P1 再上节气文案）；
- ❌ 书签拖拽排序：P0 用「上移 / 下移」按钮，拖拽手势留到 P1；
- ❌ 多用户 / 公开分享：单账号自用，按 `user_id` 隔离即可，不做分享链接；
- ❌ 书签导入导出（HTML / JSON）：P2；
- ❌ 壁纸定时轮播（每小时换一张）：P2；
- ❌ 工作台入口（对话 / 知识库）：P0 右上角头像下拉直接跳转现有路由即可，不做首页内嵌。

## 影响面

### 后端
- **新建模块**：`VeythCog-C/vc-nav/`（`com.vc.nav`），依赖 `vc-common`；
- `vc-app/pom.xml` 增加 `vc-nav` 依赖，`SecurityConfig` 放行 `/nav/**` 需登录（沿用现有 JWT 过滤链）；
- 新增 SQL 脚本：`VeythCog-C/docs/sql/012_nav.sql`（建 3 张表 + 种子数据）；
- 复用 `vc-common.s3`：`S3Bucket.public-icons`、`S3Bucket.wallpapers`、`S3PresignService`、`S3StorageClient`。

### 前端
- 新增路由：`/home`（登录后默认落地页）；
- 新增页面：`src/pages/Home/`（背景层 / 时钟 / 搜索 / 书签网格 / 右侧分类栏 / 顶栏）；
- 新增 API：`src/api/nav.ts`（分类 / 书签 / 壁纸 / 配置）；
- 新增 store：`navStore`（当前分类、当前书签列表、壁纸 URL、搜索引擎选择，persist 当前分类 id 与搜索引擎）；
- 现有路由 `/chat`、`/knowledge` 不动；右上角头像下拉新增「首页」入口。

### 数据库
- 新增 3 张表，不动现有表；
- 种子数据：给 admin 用户预置 7 个分类（主页 / 后端 / 前端 / 学习 / 工具 / 游戏 / AI）+ 每个分类 2-3 个常用书签示例。

## 验收总则（每项可演示）

启动前后端 → 登录 → 自动进入 `/home`：
1. 全屏壁纸 + 居中大时钟实时走秒；
2. 搜索框切换百度 / Google / Bing，回车新窗口跳到对应搜索结果页；
3. 右侧分类栏显示 7 个分类，**鼠标在右侧栏上下滚动，分类高亮切换，书签网格淡入淡出**；
4. 每个分类下能看到自己的书签，点「+ 添加图标」弹 Modal，填名称 + URL，保存后图标出现在网格末尾，图标自动抓取网站 favicon；
5. 右键 / 悬停书签可编辑 / 删除；
6. 右上角「编辑分类」可重命名、新增、删除分类；
7. 未登录访问 `/home` 跳登录页；登录后再访问工作台各页正常。

## 风险与待确认（review 时逐条拍板）

1. **滚轮切换分类的热区**：✅ 拍板——**覆盖整个图标页面区域**（书签网格主区域滚动即切分类），不依赖右侧竖栏可见。书签网格固定两行不溢出，不会有滚动冲突。
2. **图标来源**：✅ 拍板——**直接用各网站自己的 `https://{domain}/favicon.ico`**，前端拼 URL 直接 `<img src>`（`<img>` 不受跨域限制）；加载失败（onError）时兜底显示「网站名前 3 字 + 占位色块」，不再走后端代理 / Google favicon service。
3. **壁纸预签名**：✅ 拍板——P0 先从 S3 `wallpapers` 桶预放 20 张壁纸，用户只能在已有列表里随机 / 锁定，**不做上传**（后期再做壁纸管理功能）。每次进入首页拉 1 张随机壁纸的预签名 URL（有效期 7 天），URL 存前端内存即可，不入库。
4. **分类删除规则**：✅ 拍板——**分类下有书签时不支持删除**（前端禁用删除按钮 + 后端校验返回 409）；必须先把书签全部移走或删除，才能删分类。不做迁移逻辑。
5. **入口规则**：✅ 拍板——`/home` 作为独立入口；**根路径 `/` 直接 302 到 `/home`；点击工作台任意页面的 logo 图标也跳 `/home`**。
