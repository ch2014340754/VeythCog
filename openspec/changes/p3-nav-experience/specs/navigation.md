# 导航体验 · 行为规范

## 1. 页面标题

### 需求
1. 浏览器标签标题必须随路由变化，格式 `页面名｜渡思｜VeythCog`；未知路由保持默认标题。
2. 工具页标题使用工具中文名；工具 id 不在 registry 时回落「工具集」。
3. 从工具页返回 `/tools` 时标题同步回「工具集」。

### 验收
- 访问 `/chat` → `对话｜渡思｜VeythCog`；
- 访问 `/tools/json-formatter` → `JSON 格式化｜渡思｜VeythCog`；
- 访问 `/tools/not-exist` → `工具集｜渡思｜VeythCog`；
- 访问 `/settings/providers` → `模型配置｜渡思｜VeythCog`。

## 2. 全局命令面板

### 需求
1. `Ctrl/Cmd + K` 在除 `/login` 外的任意页打开/关闭面板；聚焦输入框。
2. 面板列出：页面、工具、书签（接口成功时）、操作。
3. 输入过滤为不区分大小写的子串匹配，匹配 label 与 keywords（书名 URL、工具描述）。
4. ↑/↓ 循环移动选中项；Enter 执行；Esc 关闭；点击项执行。
5. 执行后关闭面板、清空查询、恢复原焦点。
6. 书签项新标签打开，带 `noopener,noreferrer`。
7. 非管理员不出现系统管理相关条目。
8. 书签接口失败时静默隐藏书签分组，其余分组可用。
9. 打开时若已有书签缓存（5 分钟内）不重复请求。

### 验收
1. `/chat` 下按 Ctrl+K → 面板出现且输入框聚焦；再按 Ctrl+K → 关闭。
2. 输入 `json` → 出现「JSON 格式化」「JSON ↔ YAML」等工具；Enter 跳转 `/tools/json-formatter`。
3. 输入书签域名片段 → 出现书签项，Enter 打开新标签，`window.opener` 为空。
4. 无匹配时展示「没有匹配结果」，面板不抖动。
5. 管理员看到「系统管理」；非管理员看不到。
6. 暗色下选中行与文字保持可读（对比度 ≥ 4.5:1 于面板背景）。

## 3. 首页搜索聚焦

### 需求
1. `/home` 下按 `/` 聚焦搜索输入框；输入框/文本域/contenteditable 内不触发。
2. 带修饰键（Ctrl/Cmd/Alt）时不触发。
3. 搜索框已存在联想/AI 逻辑不变。

### 验收
- `/home` 按 `/` → `document.activeElement` 为 `.vc-search__input`；
- 在搜索框内再按 `/` → 输入框内容追加 `/`，不重复聚焦、不阻断输入。

## 4. 登录回跳

### 需求
1. 未登录访问受保护路由，登录后回到原 `pathname + search + hash`。
2. `from` 为 `/login` 或空时回落 `/home`。
3. mock token 场景保持现有行为（进 `/tools`）。

### 验收
- 未登录打开 `/knowledge?doc=12#chunk-3` → 登录 → 地址栏完整还原三个部分。

## 5. 工具集返回与标签

### 需求
1. 工具集「返回首页」按钮跳 `/home`。
2. 打开过的工具标签持久化；刷新后恢复，保留顺序与激活项。
3. 关闭标签：关闭当前项时跳到右侧相邻，无右侧跳左侧，全关回 `/tools`。
4. registry 中已删除的工具 id 不渲染。

### 验收
- 依次打开三个工具 → 刷新 → 三个标签仍在，当前工具高亮；
- 关闭中间标签 → 不跳转；关闭当前最后一个右侧标签 → 跳到左侧。

## 6. 二级侧栏出口

### 需求
1. `/settings/*` 与 `/admin/*` 左侧栏顶部有「返回首页」，点击回 `/home`。
2. 键盘可达、focus-visible 有描边反馈。

### 验收
- Tab 可聚焦该按钮，Enter 生效；文字颜色使用 `--color-text-secondary`，悬停变主色。
