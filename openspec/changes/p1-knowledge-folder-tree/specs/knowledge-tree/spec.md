# 知识库文件夹树 · 行为规范

> 版本：v1.0（2026-11-15）
> 范围：`/knowledge` 页左侧知识树 + 后端 `knowledge_folder` 相关接口
> 不含：对话页 RAG 文档勾选器（继续保持平铺列表）

## 1. 树形展示

### 需求
1. 左侧栏以树形展示：虚拟根节点「全部文档（N）」→ 文件夹 → 文档，层级不设 UI 上限（后端最多 8 层）。
2. 同一层级内**文件夹排在文档之前**；文件夹按名称升序（中文按拼音序），文档按 `updatedAt` 倒序。
3. 文件夹行显示：文件夹图标、名称、该目录下**递归文档数**（灰色小字）。
4. 文档行显示：文档图标、标题、最多 3 个标签、相对更新时间、已向量化标记（`zap`）。
5. 当前打开的文档高亮；点击已打开的文档不重新请求详情。
6. 存量文档（`folder_id = NULL`）一律显示在虚拟根节点下。

### 验收
- 进入页面即看到「全部文档 (12)」+ 目录 + 文档，层级正确。
- 目录下无文档时仍显示目录行（可展开，展开后为空）。
- 排序：两个目录「后端」「面试」按拼音序排列；同一目录下文档按最近更新时间倒序。

## 2. 默认全展开

### 需求
1. 首次进入页面、树数据到达后，**所有文件夹与虚拟根节点全部展开**。
2. 用户手动折叠后，本次会话内保持折叠；刷新页面恢复全展开。
3. 新建文件夹后，其父链自动展开，新目录可见。
4. 拖拽落入一个已折叠目录时，该目录自动展开。
5. 删除子树后，被删节点的 key 从展开集合移除。
6. 带关键词搜索时自动展开全部可见节点；清空搜索恢复搜索前的展开状态。

### 验收
- 首次进入：任意层级目录都处于展开状态（不是只展开第一层）。
- 折叠「后端」后刷新页面 → 重新全展开。
- 在折叠的「后端」里右键新建子目录 → 「后端」自动展开并显示新目录。

## 3. 新建文件夹

### 需求
1. 侧栏头部「新建文件夹」创建**根级**目录；目录右键「新建子文件夹」创建子目录。
2. 名称必填：trim 后 1~100 字，不含 `/` 与控制字符。
3. 同级不允许重名（后端唯一索引兜底，返回业务码 40000）。
4. 名称冲突、超长、空值时报错内联在弹窗输入框下方，不发请求（重名由服务端返回时 toast）。
5. 创建成功后目录出现在正确层级并自动展开，不闪整块 loading。

### 验收
- 根级建「面试」、其下建「Java」→ 树层级正确。
- 同一父级下再建「面试」→ 提示「同级已存在同名目录」。
- 名称输入 `a/b` → 提示「不能包含 `/`」。

## 4. 拖拽移动

### 需求
1. 文档拖到文件夹实体上 → 移入该文件夹。
2. 文档拖到文件夹/文档之间的间隙 → 落到该层级的同一目录（本轮不改顺序）。
3. 文档拖到虚拟根节点 → 移到根级（`folder_id = NULL`）。
4. 文件夹拖到另一个文件夹实体上 → 成为其子目录；拖到间隙 → 成为兄弟目录；拖到虚拟根 → 回到根级。
5. 禁止：拖到自身、拖到自己的后代、把文档拖到另一个文档实体内部（非间隙）。
6. 拖拽采用**乐观更新**：松手即在新位置显示；接口失败时回滚到原位置并提示原因。
7. 搜索态（关键词非空）下禁用拖拽。
8. 移动成功后不重新拉取整棵树（除非失败回滚）；当前打开文档的正文不受影响。

### 验收
- 文档 A 从根拖到「后端」→ 立即出现在「后端」下，刷新后位置一致。
- 再把 A 拖回「全部文档」→ 回到根级。
- 把「后端」拖进它自己的子目录「Java」→ 落点显示禁止态，松手无变化；直接调用接口返回「不能移动到自身或其子目录」。
- 断网/后端 500 时拖拽 → 位置回滚 + 错误 toast。

## 5. 右键菜单

### 需求
1. 在树节点上右键（不弹系统菜单）打开玻璃浮层菜单，位置跟随光标；贴近视口右/下边缘时自动翻转。
2. 菜单项：根节点「新建文件夹」；文件夹「新建子文件夹 / 新建文档 / 重命名 / 删除」；文档「重命名 / 移动到… / 删除」。
3. 点击空白、按 Esc、滚动、切换路由、执行任一菜单项后菜单关闭。
4. 「移动到…」弹窗内用同一棵树做单选（含「根目录」），作为拖拽的替代入口。
5. `F2` 对当前选中节点打开重命名弹窗。

### 验收
- 右键目录 → 弹出四项菜单，点击「重命名」弹出输入框并聚焦。
- 菜单出现在屏幕右下角附近时不超出视口。
- 按 Esc → 菜单关闭。

## 6. 重命名

### 需求
1. 目录重命名只改目录名；文档重命名**只改标题**，不修改正文、不影响 `is_vectorized` 状态。
2. 校验规则同新建（1~100 字、无 `/`、同级不重名）。
3. 成功后树内标题原地更新；若改的是当前打开文档，右侧头部标题同步更新，且**不重新加载详情**（编辑器不重解析、不闪动）。
4. 文档标题与正文首个 H1 不同步（本轮决策）；编辑器内「标题」按钮仍可定位正文标题。

### 验收
- 重命名一个已向量化文档 → 该行 `zap` 标记仍在，DB `is_vectorized` 仍为 true。
- 重命名当前打开文档 → 右侧标题立即变，编辑器内容与光标不丢。

## 7. 删除

### 需求
1. 删除文档沿用现有接口（软删除 + 显式清理向量记录）。
2. 删除**空目录**：直接删除，无二次确认。 
3. 删除**非空目录**：先统计（目录数 / 文档数）→ 二次确认弹窗写明影响范围 → 确认后递归软删除子目录与文档，并清理这些文档的向量记录。
4. 非空目录若以非递归方式请求，返回业务码 40000「目录非空」。
5. 若当前打开的文档位于被删子树内，删除后清空右侧编辑器并提示。
6. 删除后被删节点立即从树中消失；不出现整块 loading。

### 验收
- 删除空目录 → 立即消失。
- 删除含 2 个目录、5 篇文档的目录 → 确认文案显示「2 个目录、5 篇文档」；确认后整支消失；再查树与向量表均无残留（软删标记为 true、embedding 已删）。
- 删除包含当前文档的目录 → 编辑器清空并提示。

## 8. 搜索

### 需求
1. 关键词输入 300ms 防抖后查询；树只保留命中文档及其全部祖先目录。
2. 命中文档标题中的关键词片段高亮（主题色背景）。
3. 顶部显示「命中 N 篇」；无命中时显示空态文案。
4. 搜索期间禁用拖拽与「移动到…」之外的排序类操作。
5. 清空搜索后恢复完整树与搜索前的展开状态，且不重新请求完整树（使用本地快照）。

### 验收
- 搜索「Spring」→ 只剩命中文档所在目录链，标题中「Spring」高亮。
- 清空搜索框 → 完整树回来，之前折叠的目录仍保持折叠。

## 9. 兼容与权限

### 需求
1. 仍只校验「已登录」，不按用户隔离（与现有知识库一致，详见 `PROJECT_MEMORY.md` §10.1）。
2. `/knowledge/list` 行为保持不变，对话页的「知识库文档」勾选器继续可用。
3. 文档详情、保存、向量化、取消向量化、导入、导出、删除接口语义不变。
4. `PUT /knowledge/doc/{id}` 仍会在内容变更后置 `is_vectorized=false`；移动与改名不经过该接口。

### 验收
- 对话页新建会话 → 文档勾选抽屉能列出树中任意层级的文档，勾选后 RAG 召回正常。
- 在树里移动文档后，打开该文档保存一次 → 仍按原逻辑置「未向量化」。

## 10. 无感刷新

### 需求
1. 树的任何变更（新建 / 重命名 / 移动 / 删除）不得触发整块 `<Spin />` 替换。
2. 切换文档时保留上一篇正文，仅右上角显示细进度条（现有 `vc-doc-progress` 行为）。
3. 拖拽为乐观更新；其余变更成功后静默刷新一次兜底。
4. 加载期间禁用保存 / 向量化 / 导出 / 删除，避免误操作到上一篇。

### 验收
- 连续拖拽 3 次 → 树不闪、不卡顿、无整块 loading。
- 快速点两篇不同文档 → 正文不空白闪屏，只有右上角细进度条。
