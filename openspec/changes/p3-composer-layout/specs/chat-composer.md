# 规格 · 对话输入框（composer）

## 1. 布局

- 输入框容器自上而下为：知识库引用行（可选）→ 文本区（含内嵌发送按钮）→ 工具行。
- 工具行必须分为两组：左侧「工具」（知识库、附件、联网搜索、语音输入），右侧「参数」（压缩开关、模型下拉、已绑定模型标记），两组之间渲染 1px 分隔线，右组靠容器右缘对齐。
- 窄屏下工具行允许换行，但分组不合并、分隔线保持可见。

## 2. 高度拖拽

- 输入框上方必须常驻一条可见的水平抓手（44×4，圆角），hover / 键盘聚焦 / 拖拽中变为 60×4 主色。
- 抓手命中区高 12px，光标 `ns-resize`，`touch-action: none`。
- 向上拖拽增加文本区高度，向下减少；高度限制在 `[MIN_COMPOSER_HEIGHT, min(MAX_COMPOSER_HEIGHT, 55vh)]`。
- 抓手为 `role="slider"`，保留 `aria-valuemin/valuemax/valuenow` 与 `aria-label`；方向键 ↑/↓ 以 24px 步长调整高度。
- 抓手获得键盘焦点时必须显示焦点环。

## 3. 可访问性与颜色

- 分隔线 `aria-hidden="true"`。
- 所有颜色、圆角、间距、动效时长取设计令牌，不写死色值。
- 抓手的过渡只作用于 `width` / `background`，时长 `var(--duration-fast)`。
