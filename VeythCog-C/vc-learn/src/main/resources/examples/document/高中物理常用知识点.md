# 高中物理常用知识点速记

## 一、力学

### 1. 运动学
- 匀变速直线运动：`v = v₀ + at`，`x = v₀t + ½at²`，`v² − v₀² = 2ax`
- 平均速度：`v̄ = Δx/Δt`（匀变速时 `v̄ = (v₀+v)/2`）
- 自由落体：`v = gt`，`h = ½gt²`
- 打点计时器求加速度：`a = (x₃+x₄ − x₁−x₂)/4T²`

### 2. 受力分析与平衡
- 重力 `G = mg`；弹力（胡克定律）`F = kx`
- 摩擦力：滑动 `f = μN`；静摩擦由平衡或牛顿定律确定
- 共点力平衡条件：合力为零 `ΣF = 0`（常用正交分解法）

### 3. 牛顿运动定律
- 牛顿第二定律：`F = ma`（加速度方向与合外力方向一致）
- 超重：加速上升或减速下降；失重：加速下降或减速上升
- 连接体问题：整体法求加速度，隔离法求内力

### 4. 功与能
- 功 `W = Fx·cosθ`；功率 `P = W/t = Fv`（瞬时功率）
- 动能 `Eₖ = ½mv²`；动能定理：`W合 = ΔEₖ`
- 重力势能 `Eₚ = mgh`；机械能守恒条件：只有重力（或弹力）做功
- 功能关系：`W = ΔE`（功是能量转化的量度）

### 5. 曲线运动与天体
- 平抛运动：水平匀速、竖直自由落体，`t = √(2h/g)`
- 圆周运动：向心力 `F = mv²/r = mω²r`
- 万有引力：`F = GMm/r²`；第一宇宙速度 `v ≈ 7.9 km/s`

## 二、电磁学

- 电场强度 `E = F/q`，点电荷 `E = kQ/r²`
- 电势差 `U = W/q`；电容 `C = Q/U`
- 电流 `I = q/t`；欧姆定律 `I = U/R`；焦耳定律 `Q = I²Rt`
- 电阻定律：`R = ρL/S`
- 闭合电路欧姆定律：`I = E/(R+r)`；电源功率 `P = EI`
- 安培力 `F = BIL`（方向用左手定则）
- 洛伦兹力 `F = qvB`（只改变速度方向，不做功）
- 法拉第电磁感应定律：`E = nΔΦ/Δt`；导体棒 `E = BLv`
- 楞次定律：感应电流方向——阻碍引起磁通量变化的原因

## 三、其他模块

- **热学**：理想气体状态方程 `pV/T = C`（常量）
- **光学**：折射定律 `n = sinθ₁/sinθ₂`；全反射 `sinC = 1/n`
- **振动与波**：周期 `T = 2π√(L/g)`（单摆）；波长 `λ = vT`
- **原子物理**：光电效应 `Eₖ = hν − W₀`；爱因斯坦质能方程 `E = mc²`
