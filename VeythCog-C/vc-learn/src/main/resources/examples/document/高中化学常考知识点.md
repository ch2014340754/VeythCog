# 高中化学常考知识点速记

## 一、基本概念与计算

- 物质的量 `n = m/M = N/N_A = V/V_m`（标况气体 `V_m ≈ 22.4 L/mol`）
- 阿伏加德罗常数 `N_A ≈ 6.02 × 10²³ mol⁻¹`
- 摩尔质量数值上等于相对分子质量，单位 `g/mol`
- 溶液浓度：`c = n/V`；稀释定律：`c₁V₁ = c₂V₂`
- 氧化还原：升失氧、降得还（还原剂被氧化，氧化剂被还原）

## 二、元素周期律

- 同周期从左到右：原子半径减小，金属性减弱、非金属性增强
- 同主族从上到下：原子半径增大，金属性增强、非金属性减弱
- 最高价氧化物对应水化物：酸碱性随非金属性/金属性变化
- 常见金属性顺序：K > Ca > Na > Mg > Al > Zn > Fe > Sn > Pb > (H) > Cu > Hg > Ag > Pt > Au

## 三、常见元素及其化合物

### 1. 非金属
- 氯气：黄绿色有毒，`Cl₂ + H₂O ⇌ HCl + HClO`（次氯酸漂白）
- 硫：`S + O₂ → SO₂`（使品红褪色）；浓硫酸强氧化性、吸水性、脱水性
- 氮：`N₂` 稳定；氨 `NH₃` 极易溶于水，`NH₃ + H₂O ⇌ NH₃·H₂O`
- 碳族：`CO₂` 与 `NaOH` 反应量不同产物不同

### 2. 金属
- 钠：与水反应剧烈，`2Na + 2H₂O = 2NaOH + H₂↑`
- 铁：`Fe` 与稀盐酸生成 `Fe²⁺`；`Fe³⁺` 遇 `KSCN` 变红（检验）
- 铝：两性，`2Al + 6HCl = 2AlCl₃ + 3H₂↑`，`2Al + 2NaOH + 2H₂O = 2NaAlO₂ + 3H₂↑`

## 四、有机化学

- 官能团决定性质：羟基、醛基、羧基、酯基、氨基
- 烷烃取代、烯烃加成（`C₂H₄` 使溴水褪色）、炔烃加成
- 乙醇 → 乙醛 → 乙酸（氧化顺序）；酯化反应：酸 + 醇 → 酯 + 水
- 常见有机物通式：烷烃 `CₙH₂ₙ₊₂`，烯烃 `CₙH₂ₙ`

## 五、化学实验常考

- 常见气体检验：`O₂`（带火星木条）、`CO₂`（澄清石灰水）、`H₂`（点燃淡蓝色火焰）
- 分离提纯方法：过滤、蒸发、蒸馏、萃取分液、升华
- 安全操作：加热前验纯、稀释浓硫酸时**酸入水**并搅拌
