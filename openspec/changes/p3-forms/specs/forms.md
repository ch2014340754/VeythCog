# 表单体验 · 行为规范

## 1. 书签弹窗

### 需求
1. 「网址」为必填，且必须以 `http://` 或 `https://` 开头；错误显示在输入框下方。
2. 「名称」为必填（不允许纯空白），最长 64 字；错误显示在输入框下方。
3. 图标类型为「文字」时图标文字不能为空；为「上传」且尚未上传图片时提示先上传；错误显示在图标区域。
4. 保存时字段校验失败不发请求；「保存并继续」成功后清空网址/名称并重置图标选择。
5. 现有视觉（`vc-form-card`、`vc-field-label`、图标位）保持不变。

### 验收
- 空表单点保存 → 「请填写网址」「请填写名称」内联出现。
- 网址填 `abc` → 「网址需以 http:// 或 https:// 开头」内联出现。
- 文字图标清空后保存 → 图标区内联提示「请填写图标文字」。

## 2. 登录 / 注册

### 需求
1. 登录：用户名、密码均必填；空值提交时在对应字段下方提示，不弹 warning toast。
2. 注册：用户名必填；密码至少 6 位；确认密码必须与密码一致；昵称可选。
3. 服务端返回失败时保留 `message.error`，文案为中文（来自 `ApiError.message`）。
4. 登录成功/注册成功流程（回跳、3 秒自动登录）不变。

### 验收
- 空登录提交 → 「请输入用户名」「请输入密码」内联出现。
- 注册密码 `123` → 「密码至少 6 位」内联出现；确认密码不一致 → 「两次输入的密码不一致」内联出现。

## 3. 请求错误文案

### 需求
1. 请求超时 → 中文「请求超时，请检查网络后重试」，不再出现 `AbortError` 原文。
2. 网络不通/CORS → 中文「网络连接失败，请检查网络或服务地址」，不再出现 `Failed to fetch`。
3. HTTP 非 2xx 与业务错误保持原有 `ApiError` 语义（status、message、data）。

### 验收
- 断网状态点「保存」→ 提示中文网络错误；30s 超时 → 中文超时提示。
